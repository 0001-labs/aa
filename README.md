# Aa

A "text" editor.

Aa renders Markdown as you type. Add comments, diagrams, or your own commands.

```sh
npm install @0001-labs/aa
```

```js
import { createEditor } from '@0001-labs/aa'

createEditor(document.querySelector('#editor'), { value: '# A note' })
```
